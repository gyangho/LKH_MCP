# Admin frontend

React 19, TypeScript and Vite. Build with `cd frontend && npm ci && npm run build`.

The native server packages and serves generated assets. Do not commit `frontend/dist`.

For operations see [build and configuration](../docs/BUILD_AND_CONFIGURATION.md); for feature status see [features](../docs/FEATURES.md).

NanumSquare font licensing: [NANUMSQUARE-LICENSE.md](NANUMSQUARE-LICENSE.md). The app falls back to Malgun Gothic when the webfont is unavailable.
